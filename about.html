about the project

One shelf for better AI coding.

SkillShelf collects the resources worth bookmarking — installable agent skills, MCP servers, UI libraries, documentation and developer tools.

What is this?

AI coding agents get dramatically better when you feed them the right context. Installable skills — reusable packages of procedural knowledge you add with a single npx skills add command — are the fastest way to do that. SkillShelf gathers those skills next to the libraries, UI kits, MCP servers and docs you reach for every day.

What's inside

  • 248+ AI skills with copy-ready install commands.
  • UI & design resources, component libraries and icons.
  • JavaScript/TypeScript libraries, backend tools and databases.
  • MCP servers, browser automation and developer utilities.

How to use it

Search or filter the shelf, copy an install command with one click, and open the official docs whenever you need depth. Bookmark resources to build your saved shelf, or stack several skills and export them all at once.

Your data stays yours

There are no accounts and no tracking. Your saved shelf, install stack and theme live only in your own browser's local storage. Read the privacy notes for details.

Fair notice

Every resource links to its owner — SkillShelf doesn't claim their work. Review install commands before running them, as described in the terms.
