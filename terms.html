What SkillShelf provides

A free, curated directory of AI coding skills, libraries, tools and documentation, with copy-ready install commands. The site itself runs entirely in your browser.

Install commands execute third-party code on your machine. Always review a command and its source repository before running it, keep backups of important work, and never run anything you don't understand — especially with elevated permissions.
